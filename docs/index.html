Run the project

From source to desktop.

Clone the Mac branch and choose a browser preview or a native DMG build.

01 · Browser preview

Runs locally. Internet is required for complete styling and charts.

git clone --depth 1 --branch mac-version https://github.com/NerdNinjaAliaz/SuiteCRM-Mac.git
cd SuiteCRM-Mac
bash mac-desktop/run_browser.sh

02 · macOS DMG installer

Requires macOS and Xcode Command Line Tools. Default builds are not notarized.

xcode-select --install
bash mac-desktop/build_dmg.sh
open mac-desktop/dist
Prototype / security notice: This is not the original PHP/MySQL SuiteCRM app and has no live SuiteCRM server connection. The native/browser and Python/SQLite data stores do not automatically synchronize. Do not use sensitive production CRM data. The default DMG is ad-hoc signed, not Apple notarized.
